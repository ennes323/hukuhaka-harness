# Codex memory adapter

Follow the session's memory instructions for its actual root, available summaries,
registry, supporting history, and citation requirements. The generated Codex
memory store is review evidence, not an editable source. Never manually edit its
summaries, indexes, rollout summaries, or other generated files.

After the user approves the exact proposal, use the memory update mechanism
specified by that session. If it accepts an update note or request, submit it
only to the permitted destination and report submission. Re-read current memory
before claiming regeneration or application. If no supported mechanism exists,
return the approved proposal and the unavailable step.

The Codex-only SessionStart hook warns at configured size thresholds. A warning
does not establish memory quality or authorize edits.
