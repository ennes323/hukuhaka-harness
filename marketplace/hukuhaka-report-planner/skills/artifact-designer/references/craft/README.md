## How to use this set

- Start from `../reference-index.md`, not this directory. Select zero to three files that
  answer a specific unresolved problem; do not read the whole set in one pass.
- During artifact design, use the selected file to test an anchor's evidence, form, compact or expanded
  direction, and only the caveat needed to prevent misunderstanding.
- The designer records selected references in design.md and may revise the selection when a
  new representation or implementation constraint requires it. Legacy locked plans retain
  their original reference selection unless their compatibility rules permit an addition.

## Routing

The single routing table lives in `../reference-index.md`; this directory only holds the
files. Do not maintain a second file list here — two tables drift.
